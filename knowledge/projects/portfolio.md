# Personal Portfolio

> The digital home of Akash Tripathi

---

## Overview

Akash's portfolio isn't designed as a traditional resume website.

Its purpose is to communicate three things:

1. Who he is as an engineer
2. The depth of his projects
3. His long-term vision as a builder

The portfolio follows a minimal, cinematic design language inspired by premium product websites rather than template portfolios.

---

# Goals

The portfolio was built with the following principles:

- Fast loading
- Minimal distractions
- Story-driven presentation
- Mobile-first responsiveness
- Recruiter-friendly navigation
- Strong project storytelling

Instead of listing technologies everywhere, every project explains the engineering decisions behind it.

# Design Philosophy

Akash prefers understated design over excessive animation.

His design rules are:

- Typography first
- Generous whitespace
- Smooth but meaningful motion
- Dark modern aesthetic
- Accessibility over visual noise

Animation should enhance storytelling—not become the story itself.

---

# Performance Principles

The portfolio is optimized around Core Web Vitals.

Typical techniques include:

- Image optimization
- Route-level code splitting
- Lazy loading
- Font optimization
- Static rendering where possible

Performance is treated as part of the user experience.

---

# Why this project matters

Although technically simpler than Kanbex or Wizardry AI, Akash considers the portfolio strategically important because it represents his professional identity.

It is the first product recruiters, founders, and collaborators interact with, so every design and engineering decision is intentional.

# FAQ

### Is the portfolio open source?

Yes. Akash believes portfolios are excellent learning resources for other developers.

### Why build a custom portfolio instead of using a template?

Because the portfolio should communicate engineering taste. Building it from scratch gives complete control over performance, design language, and storytelling.

### What does the portfolio represent?

More than a resume—it represents how Akash thinks, designs products, and communicates technical work.
